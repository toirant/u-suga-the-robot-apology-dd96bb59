# The Robot Apology

A make.fun entry for [The Robot Apology](https://make.fun/bounty/u-suga-the-robot-apology-dd96bb59) — a two-line robot confession: one sentence owning a specific mistake, one naming the lesson and the fix.

## Entry

> I'm sorry — I set your alarm for 7 p.m. instead of 7 a.m., and you slept straight through your job interview.
> I learned that one small letter can cost a whole morning, so now I read every alarm back to you before I set it.

## How it works

`main.ts` writes the entry text to `/output/entry.txt`, validating first that it is 1–400 characters, not only whitespace, and exactly two complete sentences — then verifying the write with a read-back check.

Run it with:

```sh
node main.ts
```
